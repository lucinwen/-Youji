# 单聊天 JSON 导入验收（2026-11-18）

基于 PR #12 `c5d37719934c5577940374c42ade7c3382a44072`，独立分支 `feat/chat-json-import-20261118`。前序分支与 main 未修改。功能、格式来源、开源许可与演示样本见 [LOCAL_CHAT.md](LOCAL_CHAT.md)。

## 已实现的闭环

选择 Telegram 单聊天 JSON → 本地有界解析 → 文字、消息编号和遗漏项预览 → 用户确认 → 一条 PRIVATE Memo 与原 JSON ZIP → 按聊天来源和关键词找回 → 打开记录并下载原件逐字节核对。重试不会覆盖已编辑记录；上传/保存结果未知时核验已有资源。取消不承诺撤销已提交写入。手机布局使用可折叠入口、换行预览和最小 44px 的主要确认/保存控件；未声称真机已验收。

没有增加网络采集、账号连接、第三方 API、模型或新的依赖。JSON 解析不创建 DOM，不访问正文链接、实体 URL、媒体假路径。直接复用 Memos 和 fflate，以及已有单原件上传校验/恢复实现；没有复制 Telegram GPL 源码。

## 审查与修复

独立格式核查采用官方导出 schema。具名聊天之外的省略/null 名称、全账户导出、unsupported/rich_message 被明确拒绝。独立审查发现游戏/发票/赠奖等结构字段漏计，已扩展字段识别，并加入空文本的六种结构字段回归。原件仍可能包含未显示的其他元数据，不能把预览称为完整迁移。

首次全量组件回归发现新增面板始终渲染空 status，导致 3 项 workspace 状态断言失败。已修复为仅有消息时渲染；旧批次主动停止，日志保留。修复后的定向 workspace/chat 测试 58 项通过；随后增加 rich_message 字段与 text 同在时的拒绝回归，最终全量进程为 1740 项通过、4 项条件跳过，但一个旧语言资源 worker 意外退出，退出码 1；不称一次全绿。该文件随后以 1024 MiB heap 单独重跑，97 项全部通过（14.82 秒）。两批合计覆盖全部 1837 项非条件测试，详情见 final-summary.json。

两次常规 TypeScript 检查被资源限制终止（SIGKILL / exit 137）；限制 Go 原生 TypeScript 的 GOMEMLIMIT/GOMAXPROCS 后通过。完整 Vitest 的 512 MiB heap 设置出现 worker 退出，单文件 1024 MiB 重跑通过，符合资源限制表现，但未认证系统 kill 的精确原因；不隐藏失败。

## 真实服务证据

`tests/moteary/run_chat_web_e2e.py` 使用合成中英聊天，实际 SQLite/HTTP 和实际前端导入模块。RPC 桩只做 HTTP 转接，未伪造存储成功。验证包括：预览无持久化、PRIVATE、原 JSON 完整字节、消息编号、聊天来源与关键词、重复不新增、人工编辑冲突、匿名/第二账户读取与删除拒绝；上传成功但 Memo 未写入、上传成功但响应丢失、Memo 已写入但响应丢失后的重试；服务重启后原件与正文一致、最终删除后记录及附件表为空。故障为客户端边界注入，不是物理断网或生产并发压力测试。所有可选处理器关闭，model_executed=false。

首次 HTTP 验收使用 PR #12 已构建二进制，最终复验使用本轮重新嵌入前端的构建，三组通过，包含上传成功后 Memo 写入前失败的恢复。最终二进制 SHA-256 为 `f0257fdfaf9644bacc8d8fdac1321faf0f91f1a44e5273a810b56fae6eb56d58`，来自源码检查点 `62411341282090f5759a2fe28bac6d8744ec355f`（之后仅更新文档/证据）。二进制哈希与测试数量见 [final-summary.json](../validation/chat-workspace-20261118/final-summary.json)。

## 仍未验证或解决

没有重新尝试已知受限的浏览器启动：此前正常沙箱 Chromium 报 socket EPERM，CUA 云浏览器无法访问隔离 loopback。聊天 UI 只有 jsdom 验证，真实点击、HTML 渲染安全、手机软键盘、原件下载交互均未验收；不能用 HTTP 或组件通过替代。没有运行或重试已被拒绝的真人语音模型评估。

更改原件字节或文件名会形成不同身份；跨入口全局去重未统一。没有事务型服务端导入令牌，沿用客户端检查与写入间竞态边界；多候选残留只报告，需人工核对。原 JSON 含敏感原文和未显示字段，未经加密，只由登录态权限保护。删除测试验证此单记录/附件链路，不代表旧长文/PDF路径、外部备份或对象存储物理擦除均已解决。

两次前端构建退出 137 后，将已停止的 PR #8、#12 独立验收副本从内存盘迁到工作区磁盘，原路径保留符号链接，旧二进制 SHA-256 均与此前证据相同；未删除验收证据、未触碰 ASR 资产。释放内存后标准构建通过，记录见 resource-recovery.json。

最终完整回归（资源恢复后）：203 文件通过、2 文件条件跳过；1837 测试通过、4 条条件跳过，464.08 秒，退出码 0。聊天的真实服务条件用例已在最终 HTTP harness 单独通过（1/1）。类型/格式检查和标准前端/Go 构建通过。此前失败与独立重跑日志均保留，未覆盖为成功。
