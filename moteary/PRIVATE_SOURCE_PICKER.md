# 来源选择器：可直接运行的演示

以下第一组命令直接检出本轮 `feat/private-source-picker-20261119`，不是 #21 或 #23。适用于 Linux / WSL shell；未在 Windows 实机验证。需要 Git、Node24、pnpm、Go1.27.2、Python3。首次使用新的目录和演示数据库；安装依赖可能联网，运行服务只监听本机。

```bash
git clone --single-branch --branch feat/private-source-picker-20261119 https://github.com/lucinwen/-Youji.git youji-source-picker-demo
cd youji-source-picker-demo
git rev-parse HEAD
# 将输出与该分支草稿 PR 页面当前 HEAD 核对。
pnpm --dir web install --frozen-lockfile
pnpm --dir web release
go build -mod=readonly -o build/youji ./cmd/memos
python3 scripts/youji_demo_start.py --binary build/youji --data "$HOME/youji-demos/source-picker-demo" --port 5231 --run
```

在本机浏览器打开脚本打印的地址。数据目录已存在时启动脚本会拒绝；换一个新的演示目录，勿删除已有资料来绕过保护。项目声明pnpm11.0.1，本轮实际11.25.0；实际工具版本见验收报告。不要执行旧运行手册里的checkout命令覆盖此分支。

## 最短合成任务

1. 创建三条私密工作记录。一条为虚构复盘，另外两条均以“岗位简报”为标题，在正文写唯一关键词 `SyntheticPickerNeedle`，事件日期分别设为 `2026-10-10` 与 `2026-10-14`。本例目标是10月10日材料。刻意最后编辑10月14日的错误版本。
2. 在复盘卡片点击“选择私密来源”，输入唯一关键词并搜索。候选只显示短标题片段、事件日、记录时间和记录ID；同名时按事件日识别，ID进一步消歧。记录时间是可编辑创建时间，不冒称采集凭证。
3. 显式选择10月10日项并确认。保存仍会再次校验双方当前私密权限；候选可见不代表保存必然成功。如果材料此时撤下，显示中性错误，重新搜索。
4. 点击“打开来源原文（重新核对）”，检查选中ID及该条**当前正文**。这不是保存引用时的历史快照。随后更改关键词、候选排序或刷新，不会按同名最新项自动替换已保存引用。
5. 可清除引用。来源公开、受保护、归档或删除后，重新核对只显示不可用，不回显候选旧标题/摘要。

搜索是明确触发的字面关键词匹配，可留空查看最近候选；不是语义检索。分页“加载更多”没有全库静态快照承诺，编辑/新增期间可能改变页序，重新搜索会从第一页开始。即使某页在权限复核后变空，只要还有分页令牌就能继续加载。已有引用保持独立，只有显式确认保存才更换。

## 交互与隐私界限

原生radio选择、按钮及明确Enter/Escape处理支持键盘流程；组件测试覆盖这些事件和焦点返回，但未在真实浏览器验证radio的Space/Arrow默认行为。高级记录ID入口仍保留作备用，普通路线不需要手抄ID。

候选接口复用服务器账号限定列表及分页，固定同账户PRIVATE/NORMAL、排除当前复盘和评论。候选只返回最多80字符的标题/首行片段（截断有省略号）及必要消歧字段，不返回完整正文或摘要字段；全文关键词仍可匹配标题以外的正文。真正打开原文走独立新鲜授权接口。关闭/失焦/隐藏/账户变化/失败/保存时清除候选与选择，不用其标签回填不可用的关联。

已显示数据不能被远端瞬间收回。每次查询/保存/打开重新检查，未提供持续权限撤回推送、CAS编辑或历史快照。浏览器策略受限路径未重试，真实桌面、手机和Windows未验收；MySQL/PostgreSQL实现同步但实际数据库测试限SQLite。无新模型、依赖、许可证变化或ASR。

本轮基于 #23 且没有新数据库迁移；如果从更早版本升级，仍需备份并遵循已有日期/来源列迁移的回退说明。#23独立历史路线保留在其冻结分支，不能把它当本轮选择器版本。
