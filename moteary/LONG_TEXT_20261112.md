# 有记长文本可追溯导入 v1

这是显式 CLI 入口，不是现有页面的自动处理。页面仍按实际正文配额拒绝超限，不能把本功能理解为已完成 GUI 验收。

## 使用
服务启动后，通过已授权环境设置 `MOTEARY_API_TOKEN`，不要把令牌写进仓库或命令参数。

```sh
python3 moteary/import_long_text.py /path/to/material.txt --base-url http://127.0.0.1:5231
```

首版支持 UTF-8 TXT/Markdown，最大 256 KiB。其他编码请先自行可靠转换并保留原件，当前此入口不自动猜编码。CLI 完成才输出 `status: complete`；异常显示已核验数量、停止位置及索引 ID，不声称整体完成。

## 可追溯与检索
- 一条 PRIVATE 索引保存完整原始字节 ZIP、SHA-256 和所有计划段链接。
- 固定每段最多 4096 UTF-8 字节，不切开 Unicode 码点，不截断、不摘要。段落可能在句中分开；按顺序拼接各段正文可精确恢复解码原文。
- 每段 PRIVATE，含原文件名、原件 SHA、顺序及索引链接；每段另存其原始字节 ZIP。
- 现有资料检索按 `拾微/reference` 标签和账号范围检索所有段。关键词跨分段边界可能匹配不到，尚非语义搜索。
- 数据额外占用完整原件和分段副本，接近两份文本加 ZIP/元数据，避免隐瞒存储代价。最多 65 条记录。

## 中断与恢复
这不是服务端事务。索引包含计划链接，部分记录尚未写入时链接可暂时不存在；索引文字明确说明，**存在索引不等于完成导入**。

中断后保留已有内容，重新运行相同文件与命令。身份含认证账号，同一文件可在不同账号分别导入，不争用记录。删除索引不会级联删除分段；**显式重新导入会恢复缺失分段**，无法自动判断缺失来自故障还是用户删除。要永久删除整份资料，应删除索引及所有分段，并且不要重新运行该原文件导入。

固定版本化分段策略不随额度变化重新切分；已存在内容逐项验证权限、正文及附件 SHA，不覆盖手动修改，不删除写入状态不确定的附件。若原件或分段被修改，恢复停止并要求人工复核。改变文件字节会创建新版本，不会静默改写旧版本。

导入先校验全部索引和分段符合实际正文配额，然后每条记录再次走配额校验。网络错误、并发配额改变、存储/条数限制仍可能使操作部分完成，错误会显式暴露；不保证跨请求原子性。

## 真实验证
- Python 42 项通过，含多字节/表情重建、256 KiB 边界、固定分段身份、过小配额与空文本。
- 独立临时 SQLite 实际服务 API 49项验收通过：中途故障后恢复、重复导入不重复、索引与所有段 PRIVATE、另一账号不可读、原件 SHA、全文精确重建、关键词检索、重启恢复、手改不覆盖、导出原件恢复。
- 本增量只改 Python 与文档，没有改前端或服务端；上一提交前端 1671 项和 release/lint 结果仍为上一提交验收，不冒充本次 GUI 实测。
- 全部合成资料，无用户真实日记、账号令牌或数据库入库。
