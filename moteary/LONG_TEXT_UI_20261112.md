# 网页显式长文导入

在「一次收好一组材料」勾选「长文分段模式」，选择单个 UTF-8 TXT/Markdown（≤256KiB），选择分类、可选批注，点击预检。

预检不会上传，生成完整原件索引和固定4096 UTF-8字节分段，读取实际服务配额，任一正文超限则整组不进入保存。页面列出每条将保存的记录及正文预览。必须另行确认多次写入和存储代价，才启用保存。

- 全部 PRIVATE，不加入共享空间。索引保留完整原件ZIP，分段可按现有关键词搜索，带原件SHA及索引链接。
- 不做摘要、AI理解或截断，保留 BOM/多字节字符；不在Unicode码点中间切分。跨分段关键词可能查不到。
- 页面显示已保存或已核验 n/N；索引存在不等于全部完成。失败即停止，已确认项保留，未知项标需检查，可复核重试。
- 停止/关闭/重开后的恢复依靠重新选择相同文件、分类和批注。队列不上传到第三方，不存入浏览器持久存储。
- 删除索引不删除分段；显式重导会恢复缺失段。索引正文和保存确认均说明。
- 网页和CLI身份独立，不能跨入口保证去重。首次选择一种入口后，请用同一种入口恢复。
- 最多65条记录，约两份文本加ZIP/正文元数据空间。存储、记录数及并发配额变化仍可能导致部分完成，不保证跨请求事务。
