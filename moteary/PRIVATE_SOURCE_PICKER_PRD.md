# Private source picker

Baseline PR23 b3927af054888c8324a851f963603e9e5bfb3651. Scope: replace required manual ID entry with explicit keyword search, paginated candidates and accessible selection. No new model, generic graph or legacy relationship migration.

Contract: GET /api/youji/memos/{uid}/source/candidates?q=...&pageToken=... (optional pageSize, bounded1..20). Authenticated current owner; review must be NORMAL PRIVATE. Server fixes candidate owner=current user, PRIVATE NORMAL, excludes review. Literal keyword search via existing filter/store listing and existing pagination helpers. No client-supplied creator/filter override. JSON {candidates:[{name,label,eventDate:string|null,createdAt:RFC3339}],nextPageToken:string}. Label is a bounded title/first-line fragment, never a full body/summary; date is current record creation time (not immutable capture claim), event date retains calendar semantics. All responses no-store; no ordinary memo/list fields added. Candidate pages are live pagination, not immutable snapshots; changes can reorder between pages, explicit refresh resets.

Search only on explicit action. UI uses actual buttons and native radio/selection semantics for keyboard access, clear no-results/loading/error states, load-more, exactID+dates for same-name disambiguation. Selection does not fetch body. Save still uses existing /source PATCH validating both parties atomically; open still uses fresh /source/open. Discard candidate labels and selection when picker closes, loses page visibility/focus, account changes, request fails or save resolves; unavailable association never reuses selected label. No query/localStorage body caching.

Acceptance: synthetic same-name candidates, keyword/quote injection as literal text, pagination+self exclusion, foreign/public/archived exclusion, changed permission between selection and save rejected, no body/snippet in candidates, revoked association stays neutral. Component keyboard interactions, account/late-response cleanup; real source/date/save/retrieval regression. Previously rejected browser path not retried. SQLite actual runtime, other drivers explicit boundary.
