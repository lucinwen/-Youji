# 有记网页 PDF 采集、处理与恢复检查点

基于 PR #7 `0b9d9f3cddda752c77a4277a90f36f249a4cb654`，独立分支 `feat/pdf-workspace-flow-20261118`。不合并 main，不上传个人资料、令牌、数据库、虚拟环境或构建产物。

## 实现范围

- 工作台直接选择 PDF/分类，主动触发当前实例服务器本地 pypdf 7.1.1，展示状态、逐页纯文本、空页提示、保存进度、记录链接、取消和失败重试。文件不发给云模型。PDF 预览不写数据库；保存才创建 PRIVATE 原件与页段。
- 新增受保护原生 REST 路由 `/api/youji/pdf/processor` 与 `/api/youji/pdf/parse`，注册在现有网关，沿用登录、no-store 与请求限制；没有改 auth/token、公开 ACL、数据库 schema 或生成 proto。管理员通过两个绝对路径环境变量显式启用。
- 单实例单槽处理，16 MiB 输入、2 MiB 实际输出、64 页和 256 KiB 文本限制，17 秒父期限与原 worker 资源限额；请求取消传播至子进程。环境不包含 API 凭据；不接受用户指定命令或路径，无 shell。
- 网页专用归档名由账户/原件/类别派生记录 ID 生成。重试查同账户同名的未关联附件，原件 SHA 核验后复用；多候选拒绝保存，转入显式清理。关联前再次 GET，避免依据旧列表抢已关联附件。
- 清理预览列明记录和未关联附件，用户确认永久删除及完整评论子树。执行只接受已确认的 orphan ID 集合，范围增加则停止，重新预览；逐项复核所有权、PRIVATE、正文、ZIP 与 SHA，正文先删、索引最后删。不是组事务/CAS/物理擦除认证。
- PDF 卡片显示原文件名与页码，避免标题误取代码围栏。旧导入入口新增对 CLI/网页 PDF 原件的跨入口提示，仍不承诺全局并发去重。
- 修复 Python 图片导入失败回执遗漏预览 ID：所有已获回执的附件都会列出；未确认响应不捏造 ID，不自动删除。

## 真实验证及单元替身边界

证据目录 `validation/pdf-workspace-20261118/`：

- `pdf-web-http.json` 与 `web-module-http.log`：新临时数据库、合成普通账户，真实登录鉴权、真实 pypdf 提取中英文字与 SHA；匿名状态/解析接口 401，错误文件 422，预览及失败不写 Memo/附件。
- 实际 `pdfImport.ts` 模块由 Vitest 加载，连接真实解析/SQLite/HTTP，使用中文文件名 PDF。验证保存、页段中文检索、重复原件核验、匿名/第二账户原件与记录拒绝、清理归零。
- 真实附件提交后在客户端注入 memo 失败：重试复用原件，最终附件数等于计划数。真实附件提交后注入响应丢失：重试通过列表及 SHA 找回，不重复上传。只有未关联上传时，显式预览确认可清理；旧空预览不能扩大到新附件。故障来自客户端包装，不是服务器崩溃/真实断网。
- UI 组件测试使用 mock 模块，覆盖纯文本预览、保存/核验状态、取消、迟到结果、卸载、大小限制、清理确认与原展示快照。不能当作真实浏览器点击。
- Go 定向 race 测试覆盖现有完整网关匿名 401/no-store、配置缺失、输入/输出超限、坏 JSON、页码/版本异常、凭据环境隔离、重叠请求、在途取消与超时。这些 worker 边界测试使用受控 Python 假 worker；真实 pypdf 由 HTTP harness 单独验收。
- 旧 PDF CLI 的真实解析/SQLite/HTTP 16 项再次通过；Python 回归包含图片多附件回执故障注入，替身测试不声称实际 API 500。

## 扩大 Go 回归的失败

`go test -race ./server/... ./core/...` 返回非零：16 个包通过，`server/api` 的既有 `TestUserWebhookSigningSecretLifecycle` 因 `example.com` 的 UDP DNS 查询被沙箱禁止而失败。保留完整日志；没有禁用网络校验、跳过失败或把整套报告为通过。新增 PDF 与网关定向 race 单独通过。该限制与此前检查点一致。

## 浏览器仍未验收

上次普通沙箱 Chromium 启动被宿主 socket 权限阻止。本轮另尝试已提供的云浏览器工具：执行环境内隔离服务已在 `127.0.0.1:5231` 成功启动，但云浏览器打开该地址返回 `net::ERR_CONNECTION_REFUSED`，没有进入页面。测试服务随后停止。未关闭浏览器沙箱，未改为公网暴露或绕过宿主限制。

因此没有桌面截图、真实文件选择/点击、移动宽度、触摸/软键盘、多标签并发或两设备 UI 通过结论。真实 TypeScript 模块调用 HTTP 与 UI mock 测试应分别理解。

## 剩余边界

- 没有持久任务队列；刷新后需原文件、同文件名和分类重新解析并核验。更改分类不会自动清理旧上传。
- 同用户多客户端同时保存仍无事务唯一约束；最后 GET 与关联/DELETE 之间存在窗口。多个候选会停止保存并要求核对，而非静默挑选。
- 网页 PDF 的孤儿恢复/清理不覆盖旧 CLI、普通批量或旧长文；这些入口现在有更完整回执，但仍可能遗留未关联附件。
- 人工编辑正文后自动清理会拒绝；上游删除包含全部评论子树，必须明确确认。存储清理错误需管理员复核；404 不证明物理擦除。
- 原 PDF 仍以原件 ZIP 下载；页码用于人工核对，没有 PDF.js 页内查看器。只搜索单段正文；没有 OCR、真实 ASR、语义问答或多模态自动理解。
