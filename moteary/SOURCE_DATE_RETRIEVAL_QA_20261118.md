# 有记：按来源与保存日期找回 · 2026-11-18

## 功能与用户闭环

在既有生活/工作分类、来源采集、原件归档与音频校验试听之上，本轮补充找回条件：来源类型、保存起始日期、保存结束日期与关键词可以组合提交，继续保留当前账户、分类和空间限制。可以查找某段时间保存的生活文字、工作播客摘录、照片或音频/文档。

- 输入条件是草稿，点击“搜索资料”后才作用于结果。已应用条件单独显示。
- 日期使用设备当前时区；结束日完整包含，服务端使用次日本地零点的排除上界，不把夏令时日期硬编码为24小时。
- 非法或颠倒的日期拒绝提交，原有效筛选不变。
- “重置找回条件”清空来源、日期和关键词，保留分类、空间与当前账户约束。
- 筛选在服务端执行，沿用分页；不是从已经加载的24条卡片中做本地过滤。
- 来源是用户填写的标签，不是自动识别媒体。日期是记录创建时间，不是事情发生或录音时间；原编辑器可修改记录创建时间。
- 不将查询存入URL或浏览器存储，不增加模型出站或新的数据副本。

本轮没有新增 ASR、OCR、网页抓取或语义检索。播客摘录仍由用户显式提供，未解析音频内部内容仍不可检索。

## 复用、许可证与选择

沿用完整 Memos `26.11.0` 基线和 MIT 许可证，直接复用其 `getLocalDayTimestampRange`、服务端 CEL 过滤、分页、权限与现有 memo/attachment 存储。没有引入新依赖、数据库或派生内容服务。

收到的 faster-whisper、Docling、Mozilla Readability 属于下一步候选，本轮没有下载、安装或集成：转写涉及模型与运行资源，文档解析还涉及模型许可，网页正文提取涉及网络采集与隐私边界；本轮优先解决现有已保存资料找回问题。不能把这些候选当作已运行的能力或同任务竞品实测结论。

## 验证方法与边界

前端定向测试包含来源/分类/空间/账户组合约束、字面量关键词转义、空范围、单边日期、同一天、非法日期、反向范围、显式应用/重置和旧筛选保持。日期用例另以 `TZ=America/New_York` 运行，验证 2026-03-08 的23小时日界。

`tests/moteary/run_retrieval_e2e.py` 启动临时 SQLite 与真实 loopback HTTP 服务，使用随机密码合成账户，通过真实API创建生活/播客记录、设定测试时间并检索，测试分页、日期边界、字面量关键词、私有账户隔离、重启重新登录后找回。它不是浏览器端到端测试。临时目录自动删除，进程在 finally 中停止；没有私人材料、密钥或模型调用。

`scripts/youji_browser_smoke.py` 增加来源/日期的真实页面操作断言。浏览器结果须单独记录，不能从组件或 HTTP 测试推断已经通过。真实 ASR、实体手机、麦克风、离线同步与成熟 Demo 总体验不在本轮通过范围。
