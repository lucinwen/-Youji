# 有记：归档音频的校验试听与原件取回 · 2026-11-17

## 本轮实际增量

原来批量保存的音频只有 `.original.zip` 附件，用户必须下载 ZIP 再解压才能回听。本轮在来源卡片增加“校验并试听原件”：主动点击后，从当前实例读取 ZIP，校验通过才呈现音频播放器和原始音频下载链接。不自动播放，不上传到模型，不执行 ASR。

适用于具有一个本地原件归档、一个明确 SHA-256 的 WAV/MP3/OGG/M4A/FLAC/WebM 记录。解码支持取决于浏览器；播放失败时，已校验原件仍可下载至本机播放器。超过 16 MiB 的音频仍走已有原生编辑器路径，本轮不扩大批量内存上限。

安全与恢复边界：
- 保留原有 ZIP 和可重复导入逻辑；抽取统一校验函数供重试与试听复用。
- 流式读取至多 17 MiB，解压后原件至多 16 MiB；必须恰好一个条目、文件名一致、SHA-256 一致。拒绝外部附件链接、歧义校验值与路径异常。
- 仅同源文件路由，禁止重定向，携带已有认证，禁用请求缓存。没有后台预取。
- 读取期间可取消；关闭、切换筛选导致卡片移除或账户工作台卸载时停止音频、解除媒体源、中止请求并释放 Blob URL。没有持久化浏览器音频缓存。
- 文件名/附件/校验值变化会重新挂载播放器，避免继续使用旧的预览。
- 用户可编辑的校验值仅验证与记录的一致性，不证明来源真实；界面明确说明。
- API 错误正文不显示给用户；失败不产生未校验的下载链接，可再次尝试。
