# 聊天 JSON：SQLite 原件与正文一起保存

新版聊天 JSON 入口复用手动文本和 HTML 的 SQLite 事务，固定路由为 `POST /api/youji/chat-json/import`。原 JSON 压缩为 ZIP BLOB，和 PRIVATE 记录在同一事务提交；相同账户、文件名和原字节产生稳定标识，重复请求核对已有正文及原件，不覆盖人工编辑。身份由服务端登录态确认。

前端仍使用既有 Telegram JSON 解析器，先本地预览、明确确认后保存；不是微信或 Telegram 在线接入。原 JSON 可能包含预览未显示的身份、媒体路径、服务事件等字段，ZIP 不脱敏。服务器只检查 JSON 语法和输入限制，不认证平台来源或对话真实性。UTF-8 BOM 只在语法检查时忽略，哈希和 ZIP 保留全部原字节。

## 限制与恢复

- 仅配套新版 SQLite 服务器；其他数据库能力缺失返回 501，不回退旧分步上传。未实际验证 MySQL、PostgreSQL 或对象存储。
- 原 JSON 最大 512 KiB；派生正文最大 256 KiB，还受账户正文配额限制；HTTP 请求上限 3 MiB。前端限制和服务端验证不能互相替代。
- 旧入口已保存的记录可能因原件标识不同而冲突。打开既有记录核对，不自动迁移、覆盖或清理历史孤儿。
- 取消或失去响应不代表事务已回滚。保留相同输入重试核验；`save-unknown` 不能当成功。人工修改后重试返回冲突。
- 本次改动不修复音频、PDF、旧批量入口的多步骤写入，不承诺所有来源并发零孤儿，也不证明掉电恢复或物理擦除。
- 没有新依赖或模型，沿用 Memos MIT 底座及现有许可证。真人语音评估保持暂停。

## 演示与验收

[三分钟合成材料演示卡](THREE_MINUTE_DEMO.md) 保留已验证 PR #19 的固定回退版本，覆盖粘贴、保存、重开、关键词找回和 ZIP 核对；三分钟只是排练目标。新版本测试结果及二进制哈希见本轮 `validation/chat-atomic-demo-20261118`，以实际通过记录为准。真实 HTTP、Node Worker 和 jsdom 均不是浏览器验收。正常沙箱浏览器本轮仍因 socket 权限启动失败，没有关闭沙箱；Windows、真机手机和真实浏览器交互仍未验收。
